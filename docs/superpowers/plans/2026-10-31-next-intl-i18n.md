# Bilingual Internationalization (VI / EN) with next-intl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement bilingual routing (`/vi` and `/en`) using `next-intl` v4 on Next.js 16 App Router with structured message bundles, an accessible language toggle in `SiteHeader`, and localized core brand pages.

**Architecture:** Restructure pages under `app/[locale]/`, configured with root-level `i18n/routing.ts`, `i18n/navigation.ts`, and `i18n/request.ts`. Expose proxy/middleware for route detection and redirection. Organize translation keys into `messages/vi.json` and `messages/en.json`. Use `Link` from `@/i18n/navigation` to automatically preserve locale prefixes.

**Tech Stack:** Next.js 16.0.10, React 19.2.0, next-intl 4.14.9, Tailwind CSS v4, TypeScript 5, Lucide React.

**Spec:** `docs/superpowers/specs/2026-10-31-next-intl-i18n-design.md`

## Global Constraints
- Locales: `vi` (default) and `en`.
- URL Prefix: `always` (`/vi/...` and `/en/...`; `/` redirects to `/vi`).
- Root-level file organization without `src/` prefix (`i18n/`, `messages/`, `app/[locale]/`).
- Preserve 100% of existing authentic Vietnamese copy, numbers, and certifications.
- Adhere to `AGENTS.md` palette: Dragon Berry `#ba466d`, Soft Ivory `#fffaf3` / `#f0e8dd`, Deep Rose `#822944`, Forest Green `#6e8644`.
- Unlocalized routes: `/api/*` and static assets.

### Task 1: Core i18n Configuration & Next.js 16 Proxy Setup

**Files:**
- Create: `i18n/routing.ts`
- Create: `i18n/navigation.ts`
- Create: `i18n/request.ts`
- Create: `proxy.ts`
- Create: `middleware.ts`
- Modify: `next.config.mjs`

**Interfaces:**
- Consumes: `next-intl/routing`, `next-intl/navigation`, `next-intl/server`, `next-intl/plugin`
- Produces: `routing` (`defineRouting`), `Link`, `useRouter`, `usePathname`, `redirect` from `navigation.ts`, and request configuration loader in `request.ts`.

- [ ] **Step 1: Write `i18n/routing.ts`**

```ts
import { defineRouting } from "next-intl/routing";

export const routing = defineRouting({
  locales: ["vi", "en"],
  defaultLocale: "vi",
  localePrefix: "always",
});
```

- [ ] **Step 2: Write `i18n/navigation.ts`**

```ts
import { createNavigation } from "next-intl/navigation";
import { routing } from "./routing";

export const { Link, redirect, usePathname, useRouter } = createNavigation(routing);
```

- [ ] **Step 3: Write `i18n/request.ts`**

```ts
import { getRequestConfig } from "next-intl/server";
import { hasLocale } from "next-intl";
import { routing } from "./routing";

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested) ? requested : routing.defaultLocale;

  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  };
});
```

- [ ] **Step 4: Create Next.js 16 proxy and middleware files**

Create `proxy.ts`:
```ts
import createMiddleware from "next-intl/middleware";
import { routing } from "./i18n/routing";

export default createMiddleware(routing);

export const config = {
  matcher: "/((?!api|trpc|_next|_vercel|.*\\..*).*)",
};
```

Create `middleware.ts` (re-exports `proxy.ts` for broad Next.js compatibility):
```ts
export { default, config } from "./proxy";
```

- [ ] **Step 5: Update `next.config.mjs`**

Modify `next.config.mjs`:
```js
import createNextIntlPlugin from "next-intl/plugin";

const withNextIntl = createNextIntlPlugin("./i18n/request.ts");

/** @type {import('next').NextConfig} */
const nextConfig = {
  typescript: {
    ignoreBuildErrors: true,
  },
  images: {
    unoptimized: true,
  },
};

export default withNextIntl(nextConfig);
```

Run: `node -e 'import("./i18n/routing.ts").then(m => console.log("Routing valid:", m.routing.locales))'`
Expected: `Routing valid: [ 'vi', 'en' ]`

```tsx
import type React from "react";
import type { Metadata } from "next";
import { Geist, Geist_Mono, Playfair_Display } from "next/font/google";
import { Analytics } from "@vercel/analytics/next";
import { NextIntlClientProvider, hasLocale } from "next-intl";
import { setRequestLocale } from "next-intl/server";
import { notFound } from "next/navigation";
import { routing } from "@/i18n/routing";
import "../globals.css";

const geist = Geist({ subsets: ["latin"], variable: "--font-geist" });
const geistMono = Geist_Mono({ subsets: ["latin"], variable: "--font-geist-mono" });
const playfair = Playfair_Display({ subsets: ["latin"], variable: "--font-playfair" });

export const metadata: Metadata = {
  title: "Long Gia — Nâng tầm trái ngọt xứ Tiền",
  description: "Thanh long sạch từ vùng trồng Chợ Gạo đến thị trường toàn cầu.",
  generator: "v0.app",
};

export function generateStaticParams() {
  return routing.locales.map((locale) => ({ locale }));
}

export default async function LocaleLayout({
  children,
  params,
}: {
  children: React.ReactNode;
  params: Promise<{ locale: string }>;
}) {
  const { locale } = await params;
  if (!hasLocale(routing.locales, locale)) {
    notFound();
  }
  setRequestLocale(locale);

  return (
    <html lang={locale}>
      <body className={`${geist.variable} ${geistMono.variable} ${playfair.variable} font-sans antialiased`}>
        <NextIntlClientProvider>
          {children}
        </NextIntlClientProvider>
        <Analytics />
      </body>
    </html>
  );
}
```

- [ ] **Step 1: Create `components/language-switcher.tsx`**

```tsx
"use client";

import { useLocale } from "next-intl";
import { usePathname, useRouter } from "@/i18n/navigation";

export function LanguageSwitcher() {
  const locale = useLocale();
  const router = useRouter();
  const pathname = usePathname();

  const handleSwitch = (target: "vi" | "en") => {
    if (target === locale) return;
    const hash = typeof window !== "undefined" ? window.location.hash : "";
    router.replace(`${pathname}${hash}`, { locale: target });
  };

  return (
    <div
      role="group"
      aria-label="Language selector"
      className="inline-flex items-center rounded-full border border-[#e3d7ca] bg-[#fffaf3]/90 p-1 text-xs font-semibold shadow-sm backdrop-blur"
    >
      <button
        type="button"
        onClick={() => handleSwitch("vi")}
        className={`rounded-full px-2.5 py-1 transition-all ${
          locale === "vi"
            ? "bg-[#ba466d] text-white shadow-xs"
            : "text-[#626751] hover:text-[#822944]"
        }`}
        aria-pressed={locale === "vi"}
      >
        VI
      </button>
      <button
        type="button"
        onClick={() => handleSwitch("en")}
        className={`rounded-full px-2.5 py-1 transition-all ${
          locale === "en"
            ? "bg-[#ba466d] text-white shadow-xs"
            : "text-[#626751] hover:text-[#822944]"
        }`}
        aria-pressed={locale === "en"}
      >
        EN
      </button>
    </div>
  );
}
```
